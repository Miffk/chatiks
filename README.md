# Чатики

Бесплатный разбор переписки в Telegram. Загружаешь экспорт чата и получаешь отчёт: кто пишет первым, самый нежный час, календарь первых раз, самый громкий смех, слова года. Если подключена нейронка, добавляются ссоры, флаги, таро, сплетни и идеальное свидание.

Сайт: https://miffk.github.io/chatiks/

## Как это устроено

- **Цифры и графики** считаются прямо в браузере. Переписка никуда не загружается.
- **Блоки с оценками ИИ** включаются отдельной кнопкой и по паролю. Тогда около 1–1,5 тысячи сообщений (самые напряжённые и тёплые дни, разговоры о чувствах, последние две недели) уходят через ваш Cloudflare Worker в нейронку. Ключ нейронки хранится только в Worker, на сайте его нет.
- Цитаты из ответа нейронки сверяются с перепиской. Выдуманные цитаты отбрасываются.

```
браузер друга ──(отрывки + пароль)──► Cloudflare Worker ──(ваш ключ)──► OpenRouter
     ▲                                                                  │
     └──────────────────────────── JSON с оценками ◄────────────────────┘
```

## Как подключить нейронку (один раз, бесплатно)

### 1. Ключ OpenRouter

1. Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai).
2. Откройте **Keys** → **Create Key** и скопируйте ключ (начинается с `sk-or-`).

По умолчанию Worker пробует по очереди бесплатные `nvidia/nemotron-3.5-super-vl:free`, `google/gemma-4-31b-it:free`, `baidu/ernie-5.5-flash-preview:free` и `inclusionai/ling-3.2-flash:free`: они хорошо пишут по-русски и умеют отвечать в JSON. Список можно поменять переменной `MODEL`. Без пополнения баланса это примерно 50 запросов в день, один отчёт — один запрос. Лимиты могут меняться, их видно на [странице лимитов](https://openrouter.ai/docs/api/reference/limits).

Бесплатные модели могут сохранять запросы у себя, поэтому сайт предупреждает об этом перед отправкой.

### 2. Cloudflare Worker

1. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com).
2. **Workers & Pages** → **Create** → **Create Worker** → назовите, например, `chatiks` → **Deploy**.
3. **Edit code**, удалите всё и вставьте содержимое файла [`worker/worker.js`](worker/worker.js) → **Deploy**.
4. **Settings** → **Variables and Secrets** → добавьте:

   | Имя | Тип | Значение |
   |---|---|---|
   | `API_KEY` | Secret | ключ OpenRouter |
   | `ACCESS_PASSWORD` | Secret | пароль, который вы скажете друзьям |
   | `ALLOWED_ORIGIN` | Text | `https://miffk.github.io` |

   Необязательно: `MODEL` (другая модель, например конкретная бесплатная с `:free` на конце) и `API_URL` (любой OpenAI-совместимый адрес, например Google Gemini).

5. Скопируйте адрес Worker, вида `https://chatiks.<ваш-ник>.workers.dev`.

### 3. Адрес Worker на сайте

Откройте [`config.js`](config.js) и впишите адрес:

```js
workerUrl: "https://chatiks.<ваш-ник>.workers.dev",
```

Закоммитьте. Через минуту на сайте появится панель «Блоки с оценками ИИ».

## Как сделать экспорт чата

Telegram Desktop → чат → ⋮ → **Экспорт истории чата** → можно снять галочки с фото и видео → формат HTML или JSON. На сайте выберите получившуюся папку.

## Локальный запуск

```bash
python3 -m http.server 8000
```

Потом откройте http://localhost:8000. Сборка не нужна, это обычные HTML, CSS и JS.

## Файлы

- `index.html`, `css/style.css` — страница.
- `js/parse.js` — разбор экспорта Telegram (HTML и JSON).
- `js/analyze.js` — все метрики и выбор отрывков для нейронки.
- `js/report.js` — отрисовка отчёта и графиков.
- `js/ai.js` — промпт, запрос к Worker и проверка ответа.
- `worker/worker.js` — Cloudflare Worker.
- `config.js` — адрес Worker.
